# 🎵 Spotify Analytics Dashboard

## 📊 Sobre o projeto

Este projeto tem como objetivo realizar uma análise exploratória de dados relacionados ao Spotify, utilizando o **Power BI** para desenvolver um dashboard interativo e facilitar a visualização de informações sobre músicas e suas características.

Através da análise dos dados, o projeto busca transformar informações em indicadores e visualizações que auxiliam na interpretação dos dados musicais.

## 🛠️ Tecnologias e ferramentas utilizadas

- **Power BI:** criação do dashboard, gráficos e indicadores.
- **Microsoft Excel:** organização e armazenamento da base de dados.
- **PowerPoint:** apresentação dos resultados e desenvolvimento do projeto.

## 📈 Sobre o dashboard

O dashboard apresenta visualizações relacionadas ao desempenho e às características das músicas disponíveis na base de dados.

Entre as informações exploradas estão:

- Número de reproduções (*Streams*).
- Ano de lançamento das músicas.
- BPM (batidas por minuto).
- Características musicais.
- Comparação de dados por diferentes categorias.

## 🎯 Objetivos do projeto

- Desenvolver habilidades em análise e visualização de dados.
- Aplicar conceitos de Business Intelligence (BI).
- Trabalhar com organização e interpretação de bases de dados.
- Criar visualizações que facilitem a compreensão das informações.

## 🚀 Como visualizar o projeto

1. Faça o download do arquivo `Painel de controle Spotify.pbix`.
2. Abra o arquivo utilizando o **Power BI Desktop**.
3. Explore os gráficos, indicadores e filtros disponíveis no dashboard.
